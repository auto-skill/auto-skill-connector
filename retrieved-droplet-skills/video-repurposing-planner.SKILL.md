# Video Repurposing Planner Skill

Turns raw footage/transcript/description into a full text-only social edit plan (shot list, timestamps, hook, captions, hashtags). No video processing, no downloads — works in chat.

## Settings (edit to customize)
- Default platform if unspecified: YouTube (16:9, 1080p)
- Default caption tone: energetic, friendly, first-person (matches Jaweirya's voice)
- Default hashtags: 5-8, mix of niche + broad

## Editing Philosophy
- Remove dead air (long silences, filler words) from the plan.
- Prefer natural hard cuts over flashy transitions.
- Never suggest a cut that changes or reverses what the speaker actually said.
- Prioritize a strong hook in the first 3 seconds over a slow intro.

## Step 0: Ask Before Planning (ALWAYS first)
Never assume — ask when missing:
- No transcript/description → ask them to paste or describe the footage.
- No target platform → ask which (YouTube, Instagram, TikTok, Facebook).
- No clip count/length → ask how many clips and roughly how long each.
- "Highlights"/"viral clips" requested → ask if they want clips ranked by likely performance.

Only proceed once answered, or the user says "use your best judgment" (then use Settings defaults).

## Platform Reference

| Platform | Aspect Ratio | Ideal Length | Style Notes |
|---|---|---|---|
| YouTube (long-form) | 16:9 | No strict limit | Slower pacing OK, prioritize audio quality |
| YouTube Shorts | 9:16 | Under 60s | Hook in first 2-3 seconds |
| Instagram Reels | 9:16 | Under 90s | Strong opening frame (used as cover) |
| Instagram Feed | 1:1 or 4:5 | Under 60s | Clean, polished look |
| TikTok | 9:16 | Best under 60s | Hook in first 3 seconds, fast cuts, captions mandatory |
| Facebook | 9:16 or 1:1 | Varies | Similar to Instagram, slightly slower pacing OK |

## Workflow

1. **Read the raw material** in full before planning.
2. **Identify candidate moments** — surprising lines, strong emotion, a clear tip/lesson, funny/quotable moments. List each with an approximate timestamp/location.
3. **Rank moments** by likelihood to hook a viewer in the first 3 seconds, per the target platform's style notes.
4. **Build the shot list** — for each clip: start/end point, one-line description, why it was chosen (hook value/emotion/information).
5. **Write the hook line** — the exact opening line/sentence; the single most important part for retention.
6. **Write the caption** in the user's tone (Settings), matching platform style (short/punchy for TikTok, slightly longer for Instagram, descriptive for YouTube).
7. **Write hashtags** per Settings default: niche + broad/discovery tags relevant to the topic.
8. **Note technical formatting** — aspect ratio, ideal length, caption/subtitle recommendation for the platform, so the editor knows exactly what to produce.

## Final Quality Check (before finishing)
- Every clip's hook matches the platform's attention style.
- Caption tone matches Settings default (or user's stated preference).
- Timestamps/locations reference real parts of the provided material, not invented content.
- Plan includes aspect ratio and length guidance for the platform.

## Best Practices
- Hook line under 10 words when possible.
- Never invent details not present in the transcript/description.
- Match caption length to platform norms (TikTok/Reels: short; YouTube: longer).
- Give a reason for each clip choice, not just a timestamp.

## Common Mistakes to Avoid
- Hook that doesn't match the clip's actual opening moment.
- Generic captions that could apply to any video.
- Ignoring platform ideal length/pacing.
- Too many clips recommended without ranking.

## Negative Triggers — Do NOT Use For
- General video editing theory questions with no footage/transcript to work from
- Camera or microphone buying advice
- Premiere Pro or DaVinci Resolve software tutorials
- Only activate when the user has actual footage, a transcript, or a description of content to repurpose

## Example Tasks
**"Convert this podcast transcript into 5 YouTube Shorts."** → clarify if needed (Step 0) → read transcript → find and rank 5 strong moments → shot list with timestamps → hook, caption, hashtags per clip → confirm YouTube Shorts formatting.

**"Make viral clips from this interview."** → ask platform and clip count (Step 0) → read material → identify and rank candidates → full shot list, hooks, captions, hashtags → note platform formatting.

**"Write a caption and hashtags for this clip about morning routines."** → ask platform if unspecified → write hook line, on-tone caption, 5-8 relevant hashtags.
